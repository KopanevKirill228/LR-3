## 📌 Постановка задачи

Реализовать набор функций для решения систем линейных алгебраических уравнений (СЛАУ) методом Гаусса и методом LU-разложения. Провести сравнительный анализ времени работы алгоритмов и продемонстрировать преимущество LU-разложения при решении систем с одинаковой матрицей, но разными правыми частями.

### Основные задачи:
1. Решение СЛАУ методом Гаусса без выбора ведущего элемента
2. Решение СЛАУ методом Гаусса с выбором главного элемента по столбцу
3. LU-разложение матрицы
4. Решение треугольных систем (прямая и обратная подстановки)
5. Сравнение производительности и точности методов

---

## 🔧 Реализованные алгоритмы

### 1. Метод Гаусса без выбора ведущего элемента
**Идея:** Прямой ход метода Гаусса приводит расширенную матрицу [A|b] к верхнетреугольному виду путём последовательного исключения переменных. Обратный ход находит решение из полученной треугольной системы.

**Сложность:** O(n³)

**Ограничения:** Неустойчив при наличии малых ведущих элементов.

### 2. Метод Гаусса с выбором ведущего элемента (частичный выбор)
**Идея:** На каждом шаге прямого хода выбирается максимальный по модулю элемент в текущем столбце, и соответствующая строка переставляется на позицию ведущей. Это повышает численную устойчивость алгоритма.

**Сложность:** O(n³)

**Преимущества:** Устойчивее к ошибкам округления на плохо обусловленных матрицах.

### 3. LU-разложение
**Идея:** Матрица A представляется в виде произведения нижней (L) и верхней (U) треугольных матриц: A = L·U. Решение системы сводится к последовательному решению двух треугольных систем:
- Прямая подстановка: L·y = b
- Обратная подстановка: U·x = y

**Сложность:**
- Разложение: O(n³)
- Подстановки: O(n²)

**Преимущество:** При решении нескольких систем с одной матрицей A разложение выполняется один раз, что даёт значительную экономию времени.

### 4. Прямая и обратная подстановки
**Прямая подстановка:** Решение системы с нижней треугольной матрицей (сложность O(n²))

**Обратная подстановка:** Решение системы с верхней треугольной матрицей (сложность O(n²))

## 📁 Структура программы

### Основные файлы:

**`Solvers.h`** — основные алгоритмы решения СЛАУ:
- `GaussNopivot<T>(const SquareMatrix<T>&, b)` — метод Гаусса без выбора ведущего
- `GaussPartialPivot<T>(const SquareMatrix<T>&, b)` — метод Гаусса с частичным выбором
- `LUDecompose<T>(const SquareMatrix<T>&)` — LU-разложение матрицы
- `ForwardSubstitution<T>()` — прямая подстановка
- `BackSubstitution<T>()` — обратная подстановка
- `LUSolve<T>(const SquareMatrix<T>&, b)` — решение через LU (разложение + подстановки)
- `LUSolveDecomposed<T>()` — решение с готовым LU-разложением
- `VectorNorm<T>()` — вычисление нормы вектора
- `Residual<T>()` — вычисление невязки ||Ax - b||

> **Примечание:** Функции `GaussNopivot`, `GaussPartialPivot`, `LUDecompose` и `LUSolve` принимают `SquareMatrix<T>` (а не `RectangularMatrix<T>`), так как СЛАУ и LU-разложение определены только для квадратных матриц. Вспомогательные функции (`ForwardSubstitution`, `BackSubstitution`, `Residual`) принимают `IMatrix<T>&` — им тип не важен. Результат `LUResult<T>` хранит L и U как `RectangularMatrix<T>(n, n)` — технически n×n прямоугольные матрицы.

**`SolversTest.cpp`** — тестирование и эксперименты:
- `RandomMatrix(n, seed)` — генерация случайной `SquareMatrix<double>` n×n
- `RandomVector(n, seed)` — генерация случайного вектора
- `HilbertMatrix(n)` — создание `SquareMatrix<double>` Гильберта: H[i][j] = 1/(i+j+1)
- `Experiment_4_1()` — сравнение времени для одной системы
- `Experiment_4_2()` — множественные правые части
- `Experiment_4_3()` — проверка точности на матрице Гильберта

**Вспомогательные классы:**
- `SquareMatrix<T>` — квадратная матрица (наследует `RectangularMatrix<T>`)
- `RectangularMatrix<T>` — прямоугольная матрица
- `MutableArraySequence<T>` — динамический массив

## 📊 Результаты экспериментов

> Все результаты получены с флагом `-O2` (оптимизированная сборка).
> Без `-O2` числа в 10–100 раз больше из-за отсутствия инлайнинга и оптимизаций компилятора.

### 4.1 Сравнение времени решения одной системы

| n | Гаусс (без выб.) | Гаусс (с выб.) | LU (разложение) | LU (подстановка) | LU (итого) |
|---|------------------|----------------|-----------------|------------------|------------|
| 100 | 1.724 мс | 2.065 мс | 1.522 мс | 0.039 мс | 1.561 мс |
| 200 | 13.364 мс | 14.604 мс | 9.940 мс | 0.113 мс | 10.053 мс |
| 500 | 193.18 мс | 281.79 мс | 285.58 мс | 0.748 мс | 286.33 мс |
| 1000 | 2034.7 мс | 2471.1 мс | 1716.3 мс | 3.998 мс | 1720.3 мс |

**Масштабирование:** при удвоении n время растёт в ~8 раз — соответствует теоретическому O(n³). ✅

**Вывод:** LU-разложение быстрее метода Гаусса на 10–30% для одной системы. Подстановка O(n²) занимает < 0.3% от общего времени.

### 4.2 Экономия времени при множественных правых частях (n=500)

LU разложение (один раз): **162.313 мс**

| k | Гаусс (k систем) | LU (k подстановок) | LU всего (разл.+подст.) |
|---|------------------|-------------------|------------------------|
| 1 | 225.38 мс | 0.757 мс | 163.07 мс |
| 10 | 2585.6 мс | 7.187 мс | 169.50 мс |
| 100 | 46439 мс | 84.876 мс | 247.18 мс |

**Вывод:** При k=100 правых частях LU-подстановки в **547 раз быстрее** полного Гаусса. Полное время LU (разл.+подст.) при k=100 всего в 1.1 раза больше, чем при k=1.

### 4.3 Точность на матрице Гильберта

| n | Метод | Отн. погрешность | Невязка |
|---|-------|------------------|---------|
| 5 | Гаусс (без выб.) | 1.55e-12 | 0.00000000 |
| 5 | Гаусс (с выб.) | 3.49e-13 | 0.00000000 |
| 5 | LU | 1.55e-12 | 0.00000000 |
| 10 | Гаусс (без выб.) | 2.24e-04 | 0.00000000 |
| 10 | Гаусс (с выб.) | 1.63e-04 | 0.00000000 |
| 10 | LU | 2.24e-04 | 0.00000000 |
| 15 | Гаусс (без выб.) | **ОШИБКА** | Zero pivot encountered |

**Вывод:**
- Для n≤10 все методы работают с высокой точностью
- Выбор ведущего элемента улучшает точность (n=10: 1.63e-4 vs 2.24e-4)
- При n=15 матрица Гильберта практически сингулярна в `double`-арифметике (cond ≈ 10¹⁷ >> 10¹⁶ = 1/ε_machine) — все методы корректно выбрасывают исключение

## 💡 Выводы

### 1. Сравнительная эффективность методов

- **LU-разложение** эффективнее метода Гаусса на **10–30%** для решения одной системы
- Основное преимущество LU проявляется при **множественных правых частях**:
  - При k=100: ускорение в **547 раз** по сравнению с Гауссом
  - Разложение выполняется один раз O(n³), каждая подстановка — O(n²)

### 2. Влияние выбора ведущего элемента

- **Выбор ведущего элемента** повышает численную устойчивость
- На плохо обусловленных матрицах (Гильберта n=10) точность лучше на ~27%
- На случайных матрицах время работы сравнимо

### 3. Преимущества LU-разложения

✅ **Экономия времени** при решении систем с одинаковой матрицей
✅ **Модульность**: разложение и решение разделены
✅ **Удобство** для анализа чувствительности решения
✅ **База** для более сложных операций (обращение матрицы, вычисление определителя)

### 4. Ограничения

- Все методы неустойчивы на **плохо обусловленных матрицах** (матрица Гильберта при n≥15 вырождена в `double`)
- Требуется обработка исключений для сингулярных матриц
- Точность ограничена машинной точностью типа `double` (~10⁻¹⁶)
- Реализация не использует BLAS/LAPACK: при n=1000 работает в ~200× медленнее промышленных библиотек (numpy, Eigen) — это ожидаемо для учебной реализации

## 🚀 Сборка и запуск

### Требования
- Компилятор C++17 или выше (g++, clang++, MSVC)
- Стандартная библиотека C++

### Компиляция (рекомендуется с -O2)

```bash
g++ -std=c++17 -O2 -I. -Ilib SolversTest.cpp -o solvers
./solvers
```

> ⚠️ Без флага `-O2` результаты времени будут в 10–100 раз больше и непригодны для сравнения алгоритмов.
